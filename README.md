# 🐍 Estudos Python

O objetivo é registrar minha evolução como programador, consolidar os fundamentos da linguagem e desenvolver a capacidade de resolver problemas por meio do código.

## 📚 Conteúdos na qual estou estudando

- Fundamentos da linguagem Python
- Variáveis e tipos de dados
- Operadores
- Entrada e saída de dados
- Estruturas condicionais
- Estruturas de repetição
- Listas, tuplas e dicionários
- Funções
- Outros conceitos adicionados conforme minha evolução

*Os tópicos serão atualizados conforme eu avançar nos estudos.*
